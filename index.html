            Acessos
            Administração
            

  
            
    
            
      
            Ativar o login (uma vez só, cerca de 10 minutos)
            
      
            O login usa o Firebase, serviço gratuito do Google. Com ele, os balancetes e as anotações deixam de ficar em arquivos públicos e só quem tiver usuário e senha consegue ver.
            
      
              
        
            1. Entre em console.firebase.google.com com uma conta Google e clique em Criar um projeto. Dê o nome farol-conselho e pode desativar o Google Analytics.
              2. 
        
            2. No menu à esquerda, Criação → Authentication → Vamos começar. Em Método de login, escolha E-mail/senha, ative a primeira chave e salve.
              3. 
        
            3. Ainda em Authentication, aba Configurações → Domínios autorizados → Adicionar domínio: emersonaraujodefreitas.github.io
              4. 
        
            4. Criação → Firestore Database → Criar banco de dados. Local: southamerica-east1 (São Paulo). Modo: produção.
              5. 
        
            5. No Firestore, aba Regras: apague o que estiver lá, cole as regras abaixo e clique em Publicar.
              6. 
        
            6. Clique na engrenagem (Configurações do projeto) → em Seus apps, clique no ícone </> (Web), dê o nome site e registre. Copie o bloco const firebaseConfig = { … } e cole no campo abaixo.
              7. 
        
            7. Clique em Salvar e ativar login. Em 1 a 2 minutos o site passa a pedir login; o primeiro acesso cria o administrador.
              8. 
      
            
      
            Regras do Firestore
            
      
      
            
      
            Usa o token do GitHub já configurado em Importar balancetes para publicar o arquivo de configuração. Esses dados do Firebase não são secretos: a proteção vem das regras e do login.

            Como funciona
            Senha provisória
            
        
              
          
            • Ao criar o acesso, o site gera uma senha provisória. Ela aparece uma única vez: copie e envie à pessoa.
              • 
          
            • No primeiro acesso, a pessoa entra com a senha provisória e é obrigada a criar a própria senha.
              • 
          
            • Esqueceu a senha? Use Nova senha provisória na lista ao lado; a anterior deixa de funcionar.
              • 
          
            • Desativar bloqueia a entrada na hora, sem apagar o histórico.
              •

            Como criar o token (2 minutos)
              
      
            1. No GitHub, entre em Settings → Developer settings → Personal access tokens → Fine-grained tokens e clique em Generate new token.
              2. 
      
            2. Em Repository access, escolha Only select repositories e marque balancetefaroldeitapua.
              3. 
      
            3. Em Permissions → Repository permissions, coloque Contents como Read and write.
              4. 
      
            4. Gere o token, copie o código que começa com github_pat_ e cole no campo Token abaixo. Ele fica salvo só neste navegador.
